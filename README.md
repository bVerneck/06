# TaskFlow Dashboard

Create a fully interactive advanced task manager web application called 'TaskFlow' that surpasses Google Tasks. Use React, Tailwind CSS, and Lucide React icons. Layout: responsive desktop-first dashboard with a left Sidebar and Main Dashboard. Sidebar must include user profile area, Google-style 'Conectar Conta Google' button, customizable task lists (Trabalho, Pessoal, Estudos) with color selection and creation of new lists, quick filters (Hoje, Próximos 7 dias, Importantes), and a dedicated Recurring Tasks section. Main Dashboard must have a powerful search bar with placeholder 'Buscar tarefas por nome, tag ou notas...', a prominent 'Criar Nova Tarefa' button, and task cards displayed in a clean, modern, scannable layout. Implement a task creation/editing drawer or modal. Fields: title, notes, due date and time, attachments drag-and-drop zone (simulated uploads for images/links), advanced recurrence options (hourly, daily, weekly, custom), and simulated Gmail-linking search field. Use React state with rich mock data so the application is 100% interactive: create tasks, edit tasks, mark complete/incomplete, search/filter tasks in real time, switch between colored lists, filter by date ranges and importance, manage recurring tasks, and open/close the modal. Design language: modern SaaS dashboard using Slate tones, Indigo accents, Emerald completion states, smooth transitions, rounded cards, subtle shadows, responsive behavior, polished UX, empty states, hover states, and accessible interactions. Include sample data demonstrating all features.
